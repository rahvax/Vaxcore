# Vaxcore
Utils que reutilizo muito em outros softwares. Eu tenho uma mania de usar alguns padrões próprios em softwares, e costumo recriar diversas vezes algumas funções personalizadas para eles.

Para resolver isso resolvi começar esse projeto com a finalidade de tornar essas funções genéricas. De um esqueleto de teste até a função dinâmica e em uma biblioteca compartilhada. Vou gravar esses passos em lives que irei fazer.
